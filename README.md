# Login System

## Overview

This project implements a basic **Login System in Java** that allows users to authenticate using a username and password. The system demonstrates fundamental concepts of authentication, input validation, and simple user management.

Login systems are an essential component of modern applications, ensuring that only authorized users can access protected resources.

---

## Features

* User login authentication
* Username and password validation
* Simple console-based interface
* Basic error handling for invalid credentials

---

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* File handling / data storage

---

## How It Works

1. User enters **username and password**.
2. The system verifies the credentials.
3. If credentials match stored records:

   * Login successful
4. Otherwise:

   * Access denied

---

## Example Flow

```
Enter Username: admin
Enter Password: 1234

Login Successful
Welcome Admin
```
